# Theme Lock v1（已确认：学术答辩·白底深蓝）

## 视觉论点

用"论文插图 + 证据卡片"的克制排版讲清一次完整文本分析实验：白底承托图表，深海军蓝承担解释，
琥珀色只用于关键数字与强调线；每页一个焦点（一张图 / 一组数字 / 一条结论），留白服务于阅读节奏。

## Tokens

| 角色 | 值 |
|---|---|
| background | `#FFFFFF` |
| surface / card | `#F0F4F8` |
| primary / heading | `#1E3A5F` |
| accent（仅关键数字、强调线） | `#E8A838` |
| ink / body | `#1A1A1A` |
| muted | `#6B7B8D` |
| border / divider | `#DEE5EF` |
| danger（负向数字） | `#DC2626` |
| heading font | Microsoft YaHei（Bold for 标题） |
| body font | Microsoft YaHei |
| 页边距 | 0.65 in；内容宽 12.03 in |
| 圆角 | 0.06–0.10 in，仅用于卡片 |
| 分隔线 | 1 px `#DEE5EF` |
| 图表 | 实验原图嵌入，1 px 边框，图注 9–10 pt |

## 版式语法

- 页眉：左上标题 28pt 深蓝 Bold；副标题 10pt muted；其下 1px 分隔线。
- 页脚：左"综合实验 1 · 文本分析"8pt muted；右页码。
- 页型：封面 / KPI 行 / 三卡证据 / 左表右图 / 三步流程 / 大图+结论 / 双图 / 结论页。
- 密度：中低密度为主；单页文字不超过 5 条要点；正文 ≥12pt。

## 禁止

- 深色背景、渐变背景、装饰性光效
- 裁切/拉伸实验图表，或整页截图当内容
- 超过 5 条的项目符号堆叠
- 同一套卡片网格重复用于多数页面
- 小于 12pt 的正文；图注小于 9pt
