# Brief 与验收契约（exp1-text-analysis-ppt v1）

## 1. Brief

| 项 | 内容 |
|---|---|
| 主题 | 综合实验 1《文本分析》课程汇报 |
| 听众 | 任课教师 + 同班同学（课程评审） |
| 场景 | 第 15 周课堂展示，中文，10–12 分钟，3 人小组 |
| 目的 | 展示 11 项实验任务的完成度、方法与关键结果；讲清数据质量问题与口径选择 |
| 页数 | 14 页（16:9） |
| 素材 | 实验报告（模板版）、19 张结果图、模型对比/混淆矩阵表、GitHub 仓库 |
| 模板/品牌 | 无学校统一模板；首页需含 3 名组员姓名与分工（暂用占位） |
| 图片 | 只使用本实验自产图表 PNG，不使用外部图片；图表不裁切、不拉伸 |
| 可编辑性 | 文字、形状、表格原生可编辑；实验图表以原图嵌入（保留原始 PNG） |
| 生成模式 | Build Mode（精确坐标 + public `pptx_designer` API） |
| 主题 | `sci-paper`：白底 + 深海军蓝 `#1E3A5F` + 琥珀强调 `#E8A838`；字体 Microsoft YaHei |
